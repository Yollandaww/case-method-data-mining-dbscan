Implementation of DBSCAN clustering algorithm for an individual Case Method assignment in Data Mining. Includes dataset exploration, data preprocessing, model implementation, evaluation, visualization, and analysis.

# Case Method Data Mining - DBSCAN

Repository ini berisi dokumentasi dan implementasi tugas individu Case Method mata kuliah Data Mining menggunakan algoritma DBSCAN (Density-Based Spatial Clustering of Applications with Noise).

## Informasi Tugas

- Mata Kuliah: Data Mining
- Jenis Tugas: Individual Case Method
- Kategori: Clustering
- Algoritma: DBSCAN
- Semester: Gasal 2026/2027

## Deskripsi

Proyek ini bertujuan untuk menerapkan algoritma DBSCAN dalam menyelesaikan permasalahan clustering berdasarkan dataset yang digunakan.

Tahapan pengerjaan meliputi pemahaman dataset, data preprocessing, implementasi algoritma, evaluasi model, visualisasi hasil, dan analisis.
